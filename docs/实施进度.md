### B. 单测暴露并修复的缺陷（含一处行为修复）

1. 【行为修复】`app/core/arbiter.py` 突发合并**满仓丢消息**：同 chat 积压满 8 条再收到新消息时，原实现直接 cancel 掉旧 flush 任务并开新仓——前 8 条消息被**静默丢弃**（P0 数据丢失）。现改为换仓前先 `_route_merged` 放行积压消息（test_arbiter D5–D7 专项回归：9 连发拆 8+1 全部送达）。
2. `app/heartbeat/engine.py` 锚点完成标记丢失：`_apply` 成功时 guard 深拷贝整体替换 `self.state`，而锚点循环里 `anchors_done.append` 仍写旧对象引用 → 标记丢失、硬锚点**每拍重试**、重放漂移。改为 append 时重新取引用。
3. `app/heartbeat/engine.py` 事件溯源不完整：锚点「软锚点睡过」（pass_asleep）与「尝试未满足」（miss）两条路径只标记不落事件 → 重放无法还原 anchors_done。补两类 anchor 事件。
4. `app/outbound/shaper.py` 两处加固：虚拟时钟下令牌桶直通（否则桶空忙等死循环）；`_in_window("*")` 通配支持。
