**本轮修复的 bug**：
1. `app/api/tts.py` `/synthesize`：读 `out["result"]["audio"]` 键——TTSService 实际返回 `{url,mime,bytes,...}`，导致永远缓存 0 字节空音频+双重缓存。改为直用返回值。
2. `app/tts/store.py` `put_cache`：返回 `audio_url` 少 `/v1` 前缀（`/api/tts/audio/`→应为 `/api/v1/tts/audio/`），前端试听 404。
3. `app/gateway/server.py`：`reply_to: Any` 注解缺 `from typing import Any` 导入（PEP 563 下不炸但类型检查报错）。

**新增联调工具（入库，37 实机部署后同样可用）**：
- `scripts/e2e_mock_upstream.py`：mock LLM + mock TTS 双端口上游（无 key 联调）。
- `scripts/mock_onebot_client.py`：模拟 OneBot 对端（SnowLuma 缺席时的反向 WS 客户端，支持 `--send-private`/`--expect text|record` 断言）。
